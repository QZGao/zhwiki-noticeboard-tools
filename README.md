# zhwiki-noticeboard-tools

## 上游

此專案利用了[Xiplus的Bulletin視覺化編輯工具](https://zh.wikipedia.org/wiki/User:Xiplus/js/bulletin-editor)及[魔琴版](https://zh.wikipedia.org/wiki/User:%E9%AD%94%E7%90%B4/gadgets/bulletin-editor)的部分原始碼，此部分以[創用CC 署名-相同方式分享 4.0協議](https://zh.wikipedia.org/wiki/Wikipedia:CC_BY-SA_4.0%E5%8D%8F%E8%AE%AE%E6%96%87%E6%9C%AC)授權。
